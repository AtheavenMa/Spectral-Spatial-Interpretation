# SSI Visual Atlas

**57 pre-rendered SSI examples across six datasets.** Browse channel-resolved visualizations for RGB, multispectral, and hyperspectral imagery.

These figures are **illustrative examples**, not an additional quantitative benchmark. They are separate from the bundled, reproducible HLS demo. See the [project README](../README.md) for the method, paper results, and executable quickstart.

|---|---|---:|
| RGB | [CUB-200](#cub-200) | 10 |
