How does this work?

The browser loads the original UNet checkpoint exported to ONNX and the same original input tensor and target mask used by the Python adapter. Each selected configuration is recomputed on your device. Other cells stay observed while SSI allocates each cell's contrast among its spectral channels. Only the heatmap display is interpolated.

For all six registered models, custom checkpoints, or larger workloads, use the full Python API. This browser example uses the included HLS sample only.
