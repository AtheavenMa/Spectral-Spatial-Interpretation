# Visual Atlas source verification and re-import

The HTML gallery indexes all **57 PNG examples**. As of the work-plan 03 closeout, each of those 57 samples has a verified original tensor and the matching ONNX model is exported. The notes below describe the contract that export had to satisfy. The separately bundled HLS demo is not one of the 57.

The 57 original inputs and six models are now published for real browser recomputation. The following is the verified input contract to preserve when re-exporting or adding examples. No extra training or new ground-truth labels are needed.

## Files per Atlas sample

1. **Original input tensor**, not an RGB screenshot: NPZ with x in exact model-normalized C,H,W order, float32, plus mean/std (one value per channel).
2. **Preview RGB**, optionally rgb H,W,3 uint8 corresponding to the same crop/orientation, not a model input.
3. **Fixed target**: for classification an integer target_class in the original mapping; for segmentation an H,W ground-truth label array and fixed target_class (or separate ROI PNG).
4. **Source checkpoint** path, family adapter/architecture and immutable SHA-256. A shared checkpoint can serve multiple images.
5. **Preprocessing metadata**: original split/index, crop/resize/band-selection, no-data mask, label mapping and original band index/wavelength metadata if actually known.
6. **Sanity reference**: unperturbed selected class/GT-region logit and one inexpensive 4x4 / 1-permutation SSI reference (or a checksum and command that computes it).

## Dataset handoff

| Dataset | Atlas PNGs | Runnable model family | Inputs to preserve during re-import |
|---|---:|---|---|
| CUB-200 | 10 | cub-200 | Original RGB tensors and fixed target classes for all ten images |
| EuroSAT | 10 | eurosat | Original 13-band normalized tensors, not RGB reconstructions |
| HLS Burn Scars | 10 | hls-unet | Six-band reflectance arrays and fixed 0/1/255 masks |
| PaviaU | 10 | paviau | 103-band normalized crops, GT regions and retained band indices |
| Salinas | 10 | salinas | 204-band inputs and GT target regions |
| WHU-Hi-LongKou | 7 | whu-hi-longkou | 270-band inputs and GT target regions |

**Legacy figure labeling check:** Some previously rendered hyperspectral Atlas PNGs still contain nanometer annotations that were generated by interpolation rather than verified retained-band wavelength vectors. These embedded labels cannot be corrected by the browser gallery because they are pixels inside an existing image. When source tensors are provided, use verified sensor metadata or the original band index (Band 001, etc.) in regenerated PNGs. The new local Atlas API defaults to index labels for PaviaU, Salinas and LongKou rather than inventing nm values.

The original gallery PNG filenames and dataset grouping are listed in [atlas-catalog.json](../docs/playground/atlas-catalog.json). Ensure sample ID and target metadata match each figure. Do not substitute visually similar images or invent hyperspectral wavelength centers.

## Re-import and verification

For each exported sample, execute the already supported command, using the corresponding registered family:

~~~~bash
python -m lab.cli atlas \
  --family paviau \
  --checkpoint assets/checkpoints/paviau_unet.pt \
  --image /path/to/exported/sample_0010.npz \
  --grid 4 --baseline mean --permutations 1 \
  --output outputs/paviau_sample_0010
~~~~

This must produce an **atlas.png**, **result.json** and **attribution.npz**, with the matching target class/ROI and channel labels. Cross-check the generated input image, target region, signed SSI overlays and numeric spectral contributions against the original example, allowing expected differences when estimator settings or random seeds differ.

For future imports, validate model/input provenance, numerical references and the real browser run before modifying the published manifest. The current gallery has 57 registered runnable samples; a static PNG alone is not evidence of a new inference run.
